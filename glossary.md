# Słownik pojęć

| Pojęcie | Definicja | Gdzie |
|---|---|---|
| **Minion** | Bezobsługowy agent kodujący działający „one-shot”: dostaje zadanie i bez interakcji dowozi kompletny PR, który przegląda człowiek (model Stripe). | [SDLC06 pd-02](06-ASAI-SDLC06-ai-w-sdlc/zjazd-02_2026-11-21/homework/pracdom-02-odpowiedz.md) |
| **Blueprint** | Workflow agenta zapisany w kodzie (state machine), który przeplata węzły deterministyczne (lint, push, PR) z agentowymi (pętla LLM). | [SDLC06 pd-02](06-ASAI-SDLC06-ai-w-sdlc/zjazd-02_2026-11-21/homework/pracdom-02-odpowiedz.md) |
| **Devbox** | Jednorazowe, izolowane środowisko uruchomieniowe agenta, bez dostępu do produkcji i internetu, z danymi testowymi. | [SDLC06 pd-02](06-ASAI-SDLC06-ai-w-sdlc/zjazd-02_2026-11-21/homework/pracdom-02-odpowiedz.md) |
| **Toolshed** | Centralny serwer MCP z katalogiem narzędzi, z którego każdy agent dostaje tylko wyselekcjonowany podzbiór (least privilege dla narzędzi). | [SDLC06 pd-02](06-ASAI-SDLC06-ai-w-sdlc/zjazd-02_2026-11-21/homework/pracdom-02-odpowiedz.md) |
| **Shift-left feedback** | Najtańsze sprawdzenia (lint, unit testy) uruchamiane jak najwcześniej, zanim zmiana trafi do pełnego CI. | [SDLC06 pd-02](06-ASAI-SDLC06-ai-w-sdlc/zjazd-02_2026-11-21/homework/pracdom-02-odpowiedz.md) |
